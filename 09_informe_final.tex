\section{Introducción}

El análisis de grandes volúmenes de datos (\textit{Big Data}) constituye una herramienta fundamental para el diagnóstico sociodemográfico y la toma de decisiones basada en evidencia en salud pública. En el Perú, los nacimientos son registrados mediante el sistema en línea del Certificado de Nacido Vivo (CNV), administrado por el Ministerio de Salud (MINSA) y el Registro Nacional de Identificación y Estado Civil (RENIEC).

El presente informe técnico expone el desarrollo integral de un proyecto de Big Data aplicado sobre \textbf{4,904,793 registros de nacimientos} (2015 -- 2025). El proyecto comprende la justificación técnica ante los límites de Microsoft Excel, el diseño dimensional en Esquema Estrella, la normalización en cuadros formales hasta la Tercera Forma Normal (3FN), la implementación en Microsoft SQL Server con código limpio y sin comentarios, el pipeline ETL en Python, el análisis de patrones temporales, el entrenamiento de un modelo predictivo por regresión lineal y el despliegue de un Dashboard Web interactivo en Vanilla JavaScript.

\section{Objetivos}

\subsection{Objetivo General}
Desarrollar un proyecto integral de Big Data utilizando el conjunto de datos abiertos oficiales de los Certificados de Nacidos Vivos del Perú (2015 -- 2025), aplicando técnicas de bases de datos relacionales, normalización 3FN, pipeline ETL, análisis de patrones temporales y modelos predictivos de aprendizaje automático.

\subsection{Objetivos Específicos}
\begin{enumerate}
    \item Demostrar la necesidad de arquitecturas de Big Data frente a las limitaciones físicas de Microsoft Excel.
    \item Diseñar el Modelo Entidad--Relación en Esquema Estrella y aplicar la normalización formal hasta 3FN presentada en cuadros estructurados.
    \item Desarrollar los scripts modulares en T-SQL para Microsoft SQL Server con sintaxis limpia, sin comentarios y sin sentencias \texttt{GO}.
    \item Implementar un pipeline ETL en Python para la limpieza, imputación de valores nulos y formateo de códigos de Ubigeo INEI.
    \item Analizar el comportamiento histórico, la estacionalidad mensual y las brechas regionales.
    \item Construir un modelo predictivo mediante regresión lineal para proyectar la natalidad y tasa de cesáreas hacia 2026 -- 2030.
    \item Desplegar un Dashboard Web interactivo en HTML, CSS y JavaScript Vanilla sin frameworks.
\end{enumerate}

\section{Descripción del Dataset}

El dataset oficial contiene 4,904,793 registros y 22 columnas (791.35 MB). Una hoja de cálculo de Microsoft Excel admite un máximo de 1,048,576 filas. Por consiguiente, el dataset supera en \textbf{367.8\% (4.68 veces)} la capacidad física de Excel, provocando el truncamiento irrecuperable de más de 3.85 millones de registros y desbordamiento de memoria RAM.

Las variables abarcan datos biométricos neonatales (\texttt{PESO\_NACIDO}, \texttt{TALLA\_NACIDO}, \texttt{DUR\_EMB\_PARTO}, \texttt{sexo\_nacido}), características sociodemográficas maternas (\texttt{Edad\_Madre}, \texttt{Estado\_Civil}, \texttt{Nivel\_Intrucción\_Madre}, \texttt{DESC\_OCUPACION}, historial obstétrico) y variables asistenciales (\texttt{IdUbigeoInei}, \texttt{Ipress}, \texttt{Condicion\_Parto}, \texttt{Atiende\_Parto}, \texttt{Financiador\_Parto}).

El problema público evaluado aborda la aceleración de la transición demográfica (caída sostenida de la natalidad), la sobre-intervención quirúrgica en partos por cesárea (38.47\% nacional vs 15\% de la OMS) y la prevalencia de bajo peso al nacer en zonas rurales.

    \item \textbf{Tablas Auxiliares (Dimensiones Maestras):} \texttt{DIM\_TIEMPO}, \texttt{DIM\_UBIGEO}, \texttt{DIM\_MADRE\_PERFIL}, \texttt{DIM\_CONDICION\_PARTO}, \texttt{DIM\_ATENCION\_SALUD} y \texttt{DIM\_IPRESS}.
    \item \textbf{Cardinalidad:} Relación de 1 a N entre cada dimensión y la tabla de hechos.
\end{itemize}

CREATE NONCLUSTERED INDEX IX_FACT_TIEMPO_COV
ON dbo.FACT_NACIMIENTO (id_tiempo ASC)
INCLUDE (peso_gramos, talla_cm, duracion_embarazo_sem, edad_madre, es_bajo_peso, es_prematuro, es_madre_adolescente, es_cesarea);

CREATE PROCEDURE sp_MostrarTodosNacimientos
AS BEGIN
    SELECT TOP 100 * FROM FACT_NACIMIENTO;
END;

CREATE PROCEDURE sp_NacimientosPorRegion
    @Departamento VARCHAR(60)
AS BEGIN
    SELECT F.* FROM FACT_NACIMIENTO F
    INNER JOIN DIM_UBIGEO U ON F.ubigeo_cod = U.ubigeo_cod
    WHERE U.departamento = @Departamento;
END;

CREATE PROCEDURE sp_TotalNacimientosYCesareas
AS BEGIN
    SELECT 
        COUNT(*) AS TotalNacimientos,
        SUM(CAST(es_cesarea AS INT)) AS TotalCesareas,
        ROUND((CAST(SUM(CAST(es_cesarea AS INT)) AS FLOAT) / COUNT(*)) * 100.0, 2) AS TasaCesareasPct
    FROM FACT_NACIMIENTO;
END;
\end{lstlisting}

\section{Análisis de Patrones}

\subsection{Respuestas a las Preguntas de Investigación}
\begin{itemize}
    \item \textbf{Regiones con valores más altos:} En volumen, Lima concentra el 29.58\% (1,451,019 nacimientos), Piura el 5.84\% y La Libertad el 5.52\%. En tasa de cesáreas destacan Tumbes (49.30\%), Callao (48.90\%) y Lima (46.80\%). En bajo peso al nacer lideran Huancavelica (10.20\%) y Loreto (9.80\%).
    \item \textbf{Variación temporal:} De 2015 (417,368) a 2018 (pico de 493,990) se observó una fase expansiva (+18.36\%). A partir de 2019 se inicia una contracción sostenida que desciende hasta 376,786 en 2025 (-23.73\% acumulado).
    \item \textbf{Patrones repetitivos:} Estacionalidad intra-anual bimodal con picos en marzo (436,279) y mayo (421,288), y un mínimo constante en noviembre (384,140). Tendencia multianual estrictamente descendente en natalidad y ascendente en tasa de cesáreas.
\end{itemize}

\section{Interpretación de Resultados}

\begin{enumerate}
    \item \textbf{Pendiente del Modelo ($m = -6,998.95$):} La reducción media anual de casi 7,000 nacimientos confirma la transición hacia tasas de fecundidad por debajo del nivel de reemplazo poblacional.
    \item \textbf{Impacto Social:} La disminución de recién nacidos exigirá planificar la oferta de educación inicial y proyectar la sostenibilidad del sistema de pensiones por el envejecimiento demográfico proyectado hacia 2040.
    \item \textbf{Alerta por Cesáreas:} Con una tasa proyectada superior al 42.4\% para 2030, es indispensable fortalecer la regulación de SUSALUD y el MINSA para evitar sobrecostos médicos y cesáreas no justificadas clínicamente.
\end{enumerate}
